## Запуск проекта с помощью Docker Compose

### Предварительные требования
- Установленные Docker и Docker Compose.
- Файл `.env` с реальными значениями переменных (скопируйте `.env.example` и отредактируйте).

### Шаги для запуска

1. Клонируйте репозиторий и перейдите в корневую папку проекта.
2. Создайте файл `.env` на основе `.env.example` и заполните его своими данными (особенно `SECRET_KEY`, пароль БД).
3. Выполните команду:
   ```bash
   docker-compose up -d
